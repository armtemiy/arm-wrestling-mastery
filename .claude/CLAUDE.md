## Project Overview

Single-page landing page for armwrestling training services in Tula, Russia.
**Live site:** https://armtemiy.ru/

**Tech Stack:**
- React 18 + TypeScript
- Vite (build tool, dev server on port 8080)
- Tailwind CSS with custom design system
- React Router (minimal - just Index and NotFound pages)
- Lucide React (icons)
- shadcn/ui (Radix UI primitives - accordion, toast, tooltip, button)

## Development Commands

```bash
npm run dev          # Start dev server (localhost:8080)
npm run build        # Production build
npm run build:dev    # Development build with sourcemaps
npm run preview      # Preview production build
npm run lint         # ESLint check
npm run deploy       # Build and deploy to GitHub Pages (gh-pages branch)
```

## Architecture

### Monolithic Structure
- Entry: `src/main.tsx` → `src/App.tsx` → `src/pages/Index.tsx`
- All landing page sections are composed in `Index.tsx`
- No backend integration in code (previously used Supabase, now removed)
- No complex state management (useState only where needed)

### Page Composition (src/pages/Index.tsx)
The landing page is a linear composition of sections:
```
Navbar → Hero → Stats → Program → Training → LeadMagnet → About → MarqueeTicker → FAQ → CTA → Footer
```

Each section is a standalone component in `src/components/landing/`

### Design System (src/design-system/)
**CRITICAL:** All styling uses CSS custom properties defined in:
- `tokens.css` - colors, typography, spacing, borders, shadows
- `typography.css` - font-specific styles
- `animations.css` - keyframe animations
- `utilities.css` - utility classes

**Aesthetic:** "The Underground Forge" - dark, high-contrast, aggressive
- Primary: Crimson Red (hsl 5 85% 60%)
- Secondary: Orange-Red (hsl 15 90% 50%)
- Background: Warm Black (hsl 15 8% 6%)

**Key CSS Variables:**
```css
--color-primary-500: hsl(5 85% 60%);    /* Main accent */
--color-neutral-900: hsl(15 8% 6%);     /* Background */
--font-display: 'Clash Display', sans-serif;
--font-body: 'Satoshi', sans-serif;
--font-mono: 'JetBrains Mono', monospace;
```

### Component Guidelines
- Maximum 400 lines per file
- Use Tailwind utility classes with CSS variables
- No CSS-in-JS (except inline for dynamic values)
- Semantic HTML elements
- Accessible (ARIA attributes where needed)

### Styling Conventions
- Use design tokens: `bg-background`, `text-foreground`, `text-gradient`
- Utility classes: `.glass`, `.glass-strong`, `.card-lift`, `.stagger-item`
- Section backgrounds: `.section-dark`, `.section-light`, `.section-warm`, `.section-charcoal`
- Custom animations defined in `tailwind.config.ts`

### File Naming
- Components: PascalCase (`HeroSection.tsx`)
- Utilities: camelCase (`utils.ts`)
- Styles: kebab-case (`tokens.css`)

## Important Principles

1. **Minimal over clever** - Prefer simple, readable code
2. **No future-proofing** - Don't add features "for later"
3. **Step-by-step** - Wait for confirmation before proceeding
4. **Russian language** - Interact with user in Russian
5. **Ask questions** - Never guess when requirements are unclear

## Deployment

- **Platform:** GitHub Pages
- **Branch:** `gh-pages` (auto-generated by `npm run deploy`)
- **Domain:** Custom domain (armtemiy.ru)
- **Build output:** `dist/` directory

To deploy after changes:
```bash
git add .
git commit -m "description"
git push origin main
npm run deploy
```
