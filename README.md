# Armtemiy Lab

Лендинг для записи на персональные тренировки по армрестлингу в Туле.

🌐 **Сайт:** https://armtemiy.ru/

## Стек

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase

## Команды

```bash
npm run dev      # localhost:8080
npm run build    # сборка
npm run deploy   # деплой
```
